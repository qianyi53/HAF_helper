## M3 分析（同日第四轮，用户要求不得修改落地代码）

- 报告：docs/reports/2026-09-27-【分析】-M3-PDF解析特征分析报告.md（8 节）；分析脚本 10 个 scripts/m3_*.py；样本 data/pdf/（10 附件，_manifest.json 有正文/链接）。**haf/ 与 tests/ 未改动**
- 核心技术发现：
  1. 300 个附件**全部 PDF**，10/10 样本有文本层（非扫描件）→ pdfplumber 可用
  2. 一证一块天然成立：证书页首行 `^民用核安全设备(设计|制造|安装)许可证`；s5 实测 83 页/18家→25 块（3~5 页/块）；变更多单位 s6 一页一家（页首="单位名+许可活动范围表"）；境外确认书页首="二、国别 单位名"
  3. **变更附件是"变更后全量表"无差异标注** → 变更内容必须靠版本链 diff；变更正文含被变更证字号（86/101）
  4. **延续换证证字号会变**（S（21）20号 → S（26）17号）→ 许可证主键用（单位, 证件类型），证字号是版本属性
  5. 有效期只在 PDF 条件页（"有效期至YYYY年M月D日" / 颁发件"有效期 5 年"）
  6. 表结构 4 变体（设计/制造/安装/境外）；必现列=设备类别+核安全级别+备注；能力特征参数大类套小类（设计=通径/压力/温度，制造=结构形式/载荷等级/典型设备名）→ 必须 JSON 列
  7. 合并单元格需填充、表头两行、跨页续表需拼接
  8. 规模：820 块 / 2224 页；P0 全量 LLM ≈2.0M tokens，兜底 30% ≈0.6M tokens
- 建议输出结构（7 表）：units / licenses / license_versions / **scope_items（设备粒度核心）** / changes / registry_scopes / documents；每实体带官网链接 + 附件页码（满足用户三个查询诉求）
- 技术路线：页级预分块（防窗口/防串证）+ 块头注入 + 确定性解析优先（正则+pdfplumber）+ 轻量 LLM 仅 P0 块级归一与 P1 变更摘要兜底；不建议整份 PDF 直读
- 新待裁定：Q-L3-2 输出数据结构认可？ / Q-L3-3 技术路线认可？（Q-L3-1 LLM 通道仍待定）
