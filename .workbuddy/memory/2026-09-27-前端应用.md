## 包装页失败与结论（实测）

- 用户实测 workbuddy.link/p/ 包装页报 ERR_BLOCKED_BY_CSP：资料库页面运行时 CSP 禁止 iframe 外部站点（包装页壳仅 4KB Express 页，CSP 由平台运行时注入，响应头不可见）
- Origin 探针实测：origin=app.workbuddy.link（endpoint 无论 host/link）均被拒 → 云数据平面严格只认注册域名 app.workbuddy.host
- 结论：资料库发布路径下，数据必须来自资料库自身体系（绑定数据表或随页面打包 JSON），外部 API 不可行；用户假设正确
- iframe 包装页已下线（节点 7OEQPlBlwMInhX1YnpvE0Z 保留，可复用重发）
- 候选方案：资料库原生版 = index 数据层改本地 JSON（3 个数据集：设备索引 2565 行、licenses 552、changes 88，剥离正文/原始JSON 后 <2MB）+ zip 导入 + publish；数据更新=脚本重导出→重导入→重发布（需 WorkBuddy 会话执行 library 脚本，与 haf-sync 纯本地脚本不同）
