## M6 交付内容

- `haf/state.py`：增量状态（键 = 文函\|附件，含 sha1 与解析模式）
- `haf/pipeline.py`：`--stage weekly` 一键周更（L1→L2→L3 增量→L4 重建）；`--reparse` 强制重解析
- 撤稿同步：L1 `site_status` → L4「数据标志」+ 状态降级「待核实」（库中新增 `数据标志` / `文档状态` / `官网状态` 列，视图中暴露）
- 附件稳健性：PDF 文件头校验（非 PDF 直接标记跳过）、同一附件被多篇文函引用时各自成记录
- 实测：周更增量 ≈16 秒（附件无变化时 0 解析、0 LLM 调用）

## M7 交付内容（L5 前端）

- **浏览器版** `frontend/index.html`：双入口（按设备 / 按单位）、热门设备类目 chips、任意列排序、分页、详情抽屉（基本信息 + 变更明细 diff + 当前版本活动范围）、hash 路由；经 SDK 只读查询云数据库（`view_device_index` / `licenses` / `changes`）。
- **微信版** `frontend/wechat/核安全设备许可证查询.html`：由 `frontend/build_wechat.py` 读 haf.db 将三数据集（device 2565 / lic 552 / chg 88 + 数据截止日）内嵌进 `wechat_template.html`，~1.5MB 零外部依赖，UI 与浏览器版一致。
- **云同步** `frontend/haf-sync/sync.mjs`：haf.db → 云数据库按主键增量同步（幂等、分块、重试；写通道密钥校验），浏览器版数据随周更自动更新。
