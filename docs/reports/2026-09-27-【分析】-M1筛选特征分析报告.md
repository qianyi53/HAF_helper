# M1 筛选特征分析报告

时间：2026-09-27　|　数据：`data/nnsa_policy_docs.json`（567 篇，2021-01-06 ~ 2026-09-23）
范围裁定依据：`docs/问答对齐.md` Q1/Q2 —— 目标为**许可证、注册登记、许可证吊销/注销、单位资质吊销**；附件 PDF 数据本期不处理，仅分析标题+正文。
复现方式：`python scripts/m1_analysis.py`（输出本文全部统计数字）

---

## 一、结论先行

1. **纯脚本（域门控 + 标题事件正则）即可完成 L2 筛选，无需 LLM**。域内文档标题措辞高度模板化，规则可 100% 分类，零未分类。
2. **重要结构发现——「合并发文」现象**：注销吊销、注册登记变更、单位名称变更这三类信息**没有独立通知文件**，全部以「同时注销××原许可证」「××注册登记范围变更」等语句**内嵌在颁发/延续通知的正文中**。筛选层除文档级打标外，还需做**句级内嵌事件抽取**（正则可完成）。
3. 官网行文存在一个否定性裁定类型「**不予延续**」（域内 3 篇），原拟分类规则会误归入"延续"，规则中需先判"不予"。

## 三、域门控验证（误检排查）

对域外 338 篇做反向排查：域外但标题含「许可/变更/注册/资质」的 64 篇，逐一核验全部为：
- 核电厂**运行许可证/建造许可证**（约 20 篇）——核设施许可，非设备许可；
- **放射性废物处理/贮存/处置许可证**（约 8 篇）——另行许可类别；
- **放射性物品运输容器**制造许可/设计批准书（含 2 篇不予延续）——边界案例，见待确认 Q6；
- 其余为质量保证大纲、调试/在役检查/装换料/维修大纲、场址审查意见书、核安全导则等。

→ **域门控无误检**。域内 229 篇抽检（每事件类 5 条 + 标题开头模式统计）无域外混入。

## 五、初步筛选方案建议（规则集 v1）

### 5.1 两级流水

```
① 域门控（文档级）: /核安全设备|注册登记|单位资质/ 命中 → 域内候选
② 事件打标（文档级，仅看标题；标题全未命中时才用正文首段兜底，实测为 0 篇）:
   不予延续 > 吊销/注销 > 变更 > 延续 > 颁发/首次    (依优先级取首个命中)
   注意: 文档级事件不可用正文匹配，否则内嵌事件（同时注销/范围变更）会
   污染文档级分类——8 篇颁发通知正文含"注销"、12 篇正文含"变更"即为例证
③ 内嵌事件抽取（句级，域内文档正文）:
   同时注销句 / 注册登记范围变更句 / 单位名称变更句
```

### 5.2 建议标签体系

- `证件类型`：许可证（境内）/ 境外注册登记确认书
- `事件`：颁发 / 延续 / 不予延续 / 变更（活动范围）/ 吊销 / 注销
- `内嵌事件`：注销原证 / 注册登记范围变更 / 单位名称变更（可多个）
- `活动种类`：设计/制造/安装/无损检验（可多选；标题未注明则留空待 L3）
- `need_pdf_parse`：标题未注明活动种类 或 事件=颁发/延续（证照明细在附件）时为 true
- `match_reason`：记录命中规则与位置（标题/正文/句），可人工抽检回溯

### 5.3 技术方案结论

| 环节 | 方案 | LLM？ |
|---|---|---|
| 域门控 | 关键词正则（唯一关键词族，实测零误检） | 否 |
| 事件打标 | 标题模板正则（措辞高度模板化） | 否 |
| 内嵌事件 | 句级正则（"同时注销""范围变更""名称变更"） | 否 |
| 活动种类补全 | **在附件 PDF 中** → 归 M3 | M3 定 |

**L2 全流程无需 LLM**；LLM 的用武之地后移至 M3（PDF 结构化解析）。兜底建议：每轮增量打标后输出"未分类域内文档"清单（当前为 0），若未来出现非模板化新文种再评估引入。
