## 一、结论速览

1. **附件全部是 PDF，且 10/10 样本都有文本层**（非扫描件），可用 pdfplumber 直接抽文本与表格——**确定性解析为主、LLM 为辅**的路线成立。
2. **"一证一块"天然成立**：多单位合一的 PDF 中，每份许可证以「页首 = 民用核安全设备X许可证」分块，每块 3~5 页（证书页 + 条件页 + 附表页 + 能力参数续页）。实测 83 页 / 18 家单位 → 25~26 块。
3. **变更附件是"变更后全量表"，不带差异标注**——变更内容必须靠**版本链 diff** 推导（正文可拿到被变更的证字号，作为链接键）。
4. **证字号是强锚点**：正文或附件名可提取 69%（157/229）；其余需从 PDF 证书页取。样式统一：`国核安字S/Z/A（年份）序号号`（S=设计、Z=制造、A=安装）。
5. **有效期只在 PDF 条件页**（"许可证有效期至 2031 年 9 月 30 日" / 颁发件为"许可证有效期 5 年"）——故"状态（有效/无效）"判定依赖 PDF。
6. **表结构有 4 种变体**（设计/制造/安装/境外），"设备类别 + 核安全级别 + 备注"三列必然出现；**能力特征参数是大类套小类**（设计类=通径/压力/温度，制造类=结构形式/载荷等级/典型设备名）→ 必须 JSON 化。
7. **规模可控**：估算全量约 **2224 页 / 820 个"块"**（`scripts/m3_block_estimate.py`）；token 已由 tiktoken **实测**复核：全量 LLM 输入 **1.12M** / 输出 **1.16M**，规则优先 + 30% 兜底为 **0.34M / 0.35M**（详见补充报告 `2026-09-27-【分析】-M3补充-存储方案可行性与Token评估.md`）——**轻量 LLM 完全可行，且必须按块调用**。

### 4.1 页结构（"一证一块"）

| 文档类型 | 样本 | 页数 | 块结构 |
|---|---|---|---|
| 颁发·设计单证 | s1 | 3 | p1 证书页 → p2 条件页 → p3 附表（15行×6列） |
| 颁发·安装单证 | s2 | 3 | p1 证书页 → p2 条件页 → p3 附表（2行×5列） |
| 变更·单证 | s3 | 1 | 单页 = 范围表（5行×10列），**无证字号** |
| 变更·双证 | s4 | 2+2 | 每证：p1 范围表（12行×10列）→ p2 能力参数续页（9行×10列） |
| 延续·18家合一 | s5 | **83** | 每块 3~5 页：证书页 → 条件页 → 附表 → 能力参数；共 25~26 块 |
| 变更·20家合一 | s6 | **20** | **每页一家单位**，页首 = "××公司民用核安全设备制造许可活动范围表" |

### 4.2 分块锚点（实测命中）

| 锚点 | 正则（页首行） | 实测 |
|---|---|---|
| 证书首页 | `^民用核安全设备(设计\|制造\|安装)许可证` | s5 命中 25 处（另有 1 处首行为"附件"，次行才是标题） |
| 附表页 | `^附表$` | s5 命中 26 处 |
| 能力参数续页 | `^(设计\|制造)能力特征参数` | s4/s5 命中 |
| 单位范围表页 | `^.{4,45}(民用核(电)?安全设备).{0,12}(许可活动范围表\|许可证)` | s6 命中 19/20 页 |
| 境外确认书条目 | `^(一\|二\|三…)、` | s8 命中 4 处 |

→ **页级锚点即可完成分块**，无需 LLM 判断边界。

### 4.3 表格特征（解析难点）

1. **两行表头 + 合并单元格**：`设备类别 / 设备品种 / 核安全级别` 跨行合并；`设计能力特征参数` 为大类，下辖 `公称通径(DN) / 设计压力(MPa) / 设计温度(℃)`，`制造能力特征参数` 下辖 `结构形式 / 载荷等级(kN) / 典型设备名称`；pdfplumber 对合并单元格返回 `None`，**需向下/向右填充**。
2. **列结构 4 变体**：

| 证件/活动 | 列结构（实测） | 出现 |
|---|---|---|
| 设计许可证附表 | 设备种类(偶) + 设备类别 + 设备品种 + 核安全级别 + **设计能力特征参数** + 设计活动范围及完成形式 + 活动场所 + 备注 | s1/s4/s5 |
| 制造许可证附表 | 设备类别 + 设备品种 + 核安全级别 + **制造能力特征参数** + 主要关键工艺 + 制造活动范围及完成形式 + 活动场所 + 备注 | s3/s4/s5/s6 |
| 安装许可证附表 | **民用核设施类别** + 设备类别 + 核安全级别 + 安装活动范围及完成形式 + 备注（**无设备品种**） | s2/s5 |
| 境外注册登记 | 设备类别 + 设备品种/设备名称 + 核安全级别 + 备注 | s7/s8 |

3. **列名统计（白名单口径，10 个样本文件）**：设备类别 9、备注 9、核安全级别 9、活动场所 8、设备品种 7、主要关键工艺 4、制造活动范围及完成形式 4、设备名称 4、设计活动范围及完成形式 3、设计/制造能力特征参数 3、公称通径/设计压力/设计温度 3、设备种类 2、安装活动范围及完成形式 2、典型设备名称 2、设备品种/设备名称 2、民用核设施类别 1、结构形式 1、载荷等级 1。
4. **单元格内容非标**：`≤5030（事故工况下≤8675）`（需拆正常/事故两值）、`1、2、3级`（多值）、`主要分包项目：1.高温拉伸试验；2.表面处理；…`（列表需拆分）、`可变弹簧支吊架、恒力弹簧支吊架`（枚举）。
5. **跨页续表**：同一张表跨 2 页时表头重复（s4 设计范围表 12 行 + 9 行）→ 需续表合并。

- 有效期在**条件页**：颁发件 `许可证有效期 5 年。`；延续件 `许可证有效期至 2031 年 9 月 30 日。`

### 4.5 版本链的关键发现

- **延续/换证会变更证字号**：中核苏阀设计证 变更通知引用 `S（21）20号`，而 2026 年延续后证书为 `S（26）17号` → **证字号是"版本属性"，不是"许可证主键"**。
- 许可证身份应用 **(单位, 证件类型/活动种类)** 作为链主键，证字号随版本变化，时间轴串成版本链。
- 单位名称变更（换证时单位更名）会打断名称键 → 需"历史名称别名"表。

## 六、解析技术方案建议

### 6.1 处理流水线

```
① 附件获取与登记        URL → 本地缓存（data/pdf/），登记到 documents/附件索引
② 预处理（无 LLM）       pdfplumber 逐页抽 text + tables；文本层探测（空文本页→标记扫描件）
③ 页级预分块（无 LLM）   锚点正则切块，产出 block{类型, 页范围, 依据}
④ 块内字段抽取           确定性解析优先（正则/表格），LLM 兜底归一
⑤ 版本链与状态           规则：按 (单位,证件类型) 排序版本 → diff → 状态判定
⑥ 校验与抽检             正则/数量/交叉校验 + 10% 人工抽检
⑦ 落库                   scope_items/licenses/changes → 导出 workbuddy database 文件
```

### 6.2 预分块设计（针对"防窗口不够、防识别混淆"）

**块类型与切法（实测可行）**：

| 块类型 | 切法 | 实测依据 |
|---|---|---|
| 许可证块 | 起点 = 页首 `^民用核安全设备(设计\|制造\|安装)许可证`（首块可能为"附件"+次行标题）；终点 = 下一同类型起点前 | s5：25 证书页 / 26 附表页 → 25 块，块长 3、4、5 页（22/2/1） |
| 变更范围表块（多单位） | 页首 `^.{4,45}(民用核(电)?安全设备).{0,12}(许可活动范围表\|许可证)` → **一页一块** | s6：19/20 页命中 |
| 变更单证块 | 整个 PDF 一块（1~2 页） | s3/s4 |
| 境外确认书块 | 页首 `^(一\|二\|三…)、`（序号+国别+单位名）→ 一单位一块 | s8：4 处 / 8 页 |

**块内二级切分**：证书信息段 / 条件段 / 附表段 / 能力参数续段（段首锚点：`附表`、`设计能力特征参数`）。

**防混淆的关键：块头注入（上下文粘合）**。每个块送入解析器时，前置统一头：

```
【文档】{标题} | doc_id={t2026…} | {官网URL}
【附件】{附件名称} | {PDF URL} | 共N页
【块】第 k/N 块 | 页 {start}-{end} | 类型=许可证块 | 块内证字号={若可见}
```
理由：同一 PDF 内连续多证，字段（尤其"设备类别汇总""活动场所"）极易串证；块头 + 页范围让输出必带定位，且便于事后核对。

**块规模**：3~5 页 ≈ 1.5k~3k 字符文本 + 表格，远低于任何模型窗口 → **一次一块**即可，无需再切。

### 6.3 确定性解析优先（能不用 LLM 就不用）

| 任务 | 方案 | 依据 |
|---|---|---|
| 证字号 | 正则 `国核安证字\s*[SZA]?\s*[（(]\s*\d{2}\s*[）)]\s*\d+\s*号`（去空白） | 样本 28 个证字号样式 100% 命中 |
| 有效期 | 正则 `许可证有效期至\s*(\d{4})年(\d{1,2})月(\d{1,2})日` / `有效期\s*5\s*年` + 发证日期推算 | 实测两种措辞 |
| 单位名称/法定代表人/住所/设备类别/核安全级别 | 行首键值正则 | 证书页格式高度固定 |
| 范围表 | pdfplumber `extract_tables` + 合并单元格填充 + 两行表头合并 + 跨页续表拼接 | 10/10 样本表格可检测，列数稳定（4/5/9/10/11） |
| 分包项目 / 多值单元格 | 标点切分规则 | `1.…；2.…`、`、` 分隔 |

### 6.4 轻量 LLM 的最优使用位置（本报告核心建议）

| 优先级 | 用在哪 | 输入 | 输出 | 为什么这里最优 |
|---|---|---|---|---|
| **P0** | **块级字段抽取与归一**（证书页 + 范围表 → 结构化 JSON） | 单块（1~5 页文本 + 表格 markdown，附块头） | 小 JSON（按 5.2 schema） | 非标语义集中处：能力特征参数的自然语言、备注列的分包/条件、表头变体归一、括号内枚举拆分。块小 → 成本低、混淆低、可重试 |
| **P1** | **变更内容摘要**（对规则 diff 结果做自然语言化 + 完整性检查） | 结构化 diff（新增/删除/修改行） | 一句话摘要 + 类型判定 | diff 结果已是结构化小输入，LLM 只做表达与归类，风险低 |
| **P2** | 异常块修复（列错位、单元格粘连、文本层残缺） | 单页原始文本/表格 | 修正后表格 | 仅在前两级规则失败时触发，占比预计 <5% |
| **不建议** | ① 整份 PDF（如 83 页）直读；② 纯表格搬运（pdfplumber 更准更省）；③ 状态判定/版本链（规则足够且需可解释）；④ 无分块直接批量喂 | — | — | 窗口/成本/混淆三重风险 |

**调用量估算**（`scripts/m3_block_estimate.py` + `scripts/m3_token_estimate.py` 实测）：块数 ≈ **820**；实测单块输入 ≈1.37k tok（正文953+块头158+提示词260）、单块输出 ≈1.42k tok。全量：输入 **1.12M / 输出 1.16M**；规则优先 + 30% 兜底：**0.34M / 0.35M**（含 1.3× 重试 0.44M/0.45M）。**结论：全量也属极低成本，建议采规则优先 + LLM 兜底**。

### 6.5 版本链、diff 与状态判定

```
版本链: (单位规范化名, 证件类型) → 按生效日期排序的 license_versions
变更内容: 相邻版本 scope_items 行级 diff，行键=(设备类别, 设备品种, 核安全级别, 活动场所)
          → {新增[], 删除[], 修改[{字段, before, after}]}；再由 P1 生成摘要
状态判定:
  有效   = 最近版本事件 ∈ {颁发, 延续} 且 (有效期止 ≥ 今日)
  无效   = 有效期已过(到期未延续) 或 事件=不予延续
  已注销 = 出现"同时注销"内嵌事件（换证注销原证）
  注: 变更不改变有效性，仅更新内容
```

**基线问题**：cutoff=2021（Q-L1-1 不回溯）→ 部分许可证的"首个可见版本"其实是变更后表，无法 diff 出初版差异；建议此类变更标记 `diff_basis=missing_baseline`，先入库、后续如回溯再补。

### 6.6 校验策略

| 校验 | 规则 |
|---|---|
| 证字号 | 必填（除纯范围表件可回填正文证字号），字符集/年份/序号合规 |
| 有效期 | 与发证日期、5 年规则、延续件日期一致性 |
| 块完整性 | 块内须含 ≥1 张范围表；范围行数 ≥1；多单位篇的块数 ≈ 标题"等 N 家" |
| 交叉 | 变更通知正文证字号 ↔ 附件归属；延续清单单位数 ↔ 块数 |
| 人工抽检 | 每批 10%（含能力参数最复杂行），抽检结果反馈提示词/规则迭代 |
