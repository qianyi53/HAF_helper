## 一、列表层（全量覆盖验证）

| 项目 | 结果 |
|---|---|
| 真实列表入口 | `https://nnsa.mee.gov.cn/zcwj/haqjwj/wj/`（首页 `/zcwj/haqjwj/` 只显示最近15条） |
| 分页方式 | **纯静态分页**：`index.html`、`index_1.html` … `index_199.html`（页面脚本 `createPageHTML(200, 0, "index", "html")`） |

## 二、详情层（字段可用性验证）

详情页存在**两套系统**，结构一致、字段相同：

- **新版（2018年后）**：`www.mee.gov.cn/xxgk2018/xxgk/xxgk09/YYYYMM/tYYYYMMDD_*.html`
- **旧版（2007–2018）**：`www.mee.gov.cn/gkml/zj/haq/YYYYMM/tYYYYMMDD_*.htm`

### 你要求的字段逐一核对

| 要求字段 | 可获得性 | 来源与说明 |
|---|---|---|
| 名称 | ✅ | meta `ArticleTitle`，与列表标题一致 |
| 索引号 | ⚠️ 页面上不存在 | 详见下文"元数据缺口" |
| 分类 | ✅ | meta `ColumnName` = "国家核安全局文件"（本栏目恒定值） |
| 发布机关 | ✅ | 页面无独立字段，但落款恒为"国家核安全局"，可按规则默认 |
| 生成日期 | ✅ | meta `PubDate`（发布日期）；**成文日期**可从正文落款解析（如"2026年9月17日"） |
| 文号（"问好"） | ✅ 部分文件有 | 从正文/标题正则解析（如"环核〔2026〕xx号"），多数批复类文件无文号 |
| 主题词 | ⚠️ 页面上不存在 | meta `Keywords` 基本为空 |
| 正文 | ✅ | `div.content_body_box` 纯 HTML，结构规整，去标签即得纯文本 |
| 附件及链接 | ✅ | 正文内 `<a href="./W0*.pdf">` 相对链接，可拼接为绝对地址（Demo 已完整解析 PDF 附件） |

### 元数据缺口说明（索引号、主题词）

对旧版和新版详情页均已做全文检索：**索引号、主题分类、主题词这些政府信息公开目录字段没有发布在文件页 HTML 中**，MEE 的信息公开目录系统（/xxgk2018/xxgk/xxgkml/）也只跳转回官网首页，无独立接口。因此：

- 建议主数据表以 **详情页 URL（含文档ID）** 作为唯一索引号替代（如 `t20260922_1170491`）；
- 主题词留空，后续可在入库时用关键词提取自行生成。
