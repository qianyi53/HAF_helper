## 二、实现要点

### 2.1 L3 分块与抽取（按 M3 报告 §6.2/§6.3）
1. **页级锚点分块**：证书页（`民用核安全设备X许可证`，兼容首页 "附件 / 各单位… / 真标题" 多层前缀）、单位范围表页、境外条目页（`一、…`）；同一单位跨页续表自动去重。
2. **确定性抽取**：证书页键值（证字号/单位/法定代表人/住所/设备类别/核安全级别，支持字段名内含空格如 "单 位 名 称："）；有效期（"有效期至YYYY年M月D日" 或 "有效期5年" + 发证日期推算）；范围表（**多行碎片化表头自动合并**、合并单元格向下填充、跨页续表、表一/表二双表）。
3. **能力特征参数 JSON 化**：两行表头（公称通径DN/设计压力/设计温度）与单行表头（结构形式/载荷等级/典型设备名称/材料类别/成品重量/壁厚/管板厚度/堆型功率）统一进 JSON；"≤5030（事故工况下≤8675）" → `{"值":5030,"上限":true,"附加":{"事故工况":{"值":8675}}}`。
4. **换行/空格清洗**：中文单元格去换行空格，拉丁为主的单元格（英文单位名/地址）保留单词间空格。

### 2.2 LLM 接入与兜底（Q-L3-1）
- `haf/llm.py`：配置顺序 env → `config.local.json`（**注：报告产出时的"本地 key 文件"方式已废弃，统一为 config.local.json，模板见 config.example.json**）；默认 `deepseek-flash` 且 **关闭思考链**（`thinking: disabled`，实测比默认快且省）；`response_format=json_object`；结果按（模型+提示词）哈希缓存；用量写入 `data/llm_cache/_usage.json`。
- **兜底触发**（规则优先）：关键字段缺失（证字号/单位/无范围行）**或**范围行关键列缺失比例 > 30%。
- **分片与隔离**：单块载荷 > 12000 字符自动按页切片；单块失败不影响其他块（记入 `block_error`）；LLM 返回 JSON 支持围栏/夹带文字/**截断修复**。

### 2.3 版本链与状态（按 M3 §6.5）
- 许可证主键 =（规范化单位名, 证件类型），**证字号作为版本属性**（延续换证变号不断链）；变更范围表版本自动继承上一版证字号。
- 变更内容 = 相邻版本范围行级 diff（行键＝设备类别+品种+级别+场所 → 新增/删除/修改），并生成规则式摘要。
- 状态判定：不予延续 / 有效期已过 → 无效；**内嵌"同时注销"引用**（从 L2「注销」标注文档正文抽取）→ 已注销；否则有效。

## 五、开发过程中发现并修正的问题

| # | 问题（真实数据暴露） | 修正 |
|---|---|---|
| P1 | 证书标题在页首第 3 行（"附件 / 各单位民用核安全设备许可证 / 真标题"）→ 漏检首证、少识别 1 家单位 | 锚点扫描扩展到前 4 行并跳过"附件"前缀行（s5 25→26 块、s6 19→20 家） |
| P2 | 字段名内含空格（"单 位 名 称："）→ 境外单位名抽不到 | 键名正则允许字符间空格 |
| P3 | 数据行含"活动场所仅限于…"被误判为表头行 | 表头判定改为**单元格级严格匹配**（短文本且完整等于表头名） |
| P4 | 表头被 PDF 拆成 8 行碎片（无锡西塘页）→ 整表无法解析 | **多行表头自动合并 + 参数组跨度填充**（该页从 0 行恢复到 10 行/3 参数） |
| P5 | 合并单元格导致核安全级别大面积缺失（1786 行） | 核安全级别纳入向下填充 → 缺 400 行 |
| P6 | 规则行残缺（缺设备类别 97 行） | 新增"缺失比例 > 30% 触发 LLM"策略 → 缺 14 行 |
| P7 | 一份变更通知变更同一单位两个证 → `change_id` 冲突被覆盖（88→41 条） | `change_id = C{doc_id}-{license_id}` 唯一化 |
| P8 | LLM 输出被 max_tokens 截断 → 整份附件解析中断 | 载荷分片（12k 字符）+ max_tokens 8000 + **截断 JSON 修复** + 单块失败隔离 |
| P9 | 能力参数可读串重复单位（"DN≤1050DN"） | 单位与名称相同时不重复拼接 |

## 六、已知缺口与遗留（建议下一步处理）

| # | 缺口 | 影响 | 建议 |
|---|---|---|---|
| D1 | 1 个附件链接实为非 PDF 文件（`P020160115354384401490.pdf`，报 "No /Root object"） | 少解析 1 个附件 | 下载后做文件头校验（`%PDF-`）并记 `状态=非PDF`，避免重试 |
| D2 | 核安全级别缺失 370 行（10%） | 按级别检索会漏 | 内容多为跨页续表/极窄列；可对剩余残缺块再跑一轮 LLM 兜底（成本 < 0.2M tok） |
| D3 | 设备品种缺失 443 行 | 按品种检索漏 | 部分类型（安装类、境外表）本身无品种列，属正常；其余可 LLM 补 |
| D4 | 变更 diff 基线缺失（2021 前的版本未回溯，Q-L1-1 裁定不回溯） | 首批变更的"变更前"为空 | 已按裁定处理；如需完整 diff，可对重点单位单独回溯更早版本 |
| D5 | 状态判定依赖有效期与注销引用，尚无"主动吊销"语料 | 效果有限 | 语义规则已就位，未来增量数据出现即可自动生效 |
| D6 | 设备类别/品种同物异名未归一（如"安全阀"与"安全阀（弹簧式）"） | 检索召回略降 | 建议下一步做**词表归一映射表**（LLM 聚类 + 人工确认） |
